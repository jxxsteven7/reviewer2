# Security

## Reporting a problem

Report a security problem privately, through GitHub's [private vulnerability reporting](https://github.com/jxxsteven7/reviewer2/security/advisories/new), never in a public issue, a pull request or the site's feedback. Only the maintainers and you see the report. Say what you found, how to reproduce it and what someone could do with it. Try it on a copy of your own ([Running locally](README.md#running-locally)), not on other players' games or accounts on the site.

## What happens then

We fix the problem and release the fix first, and then publish the advisory. If you agree, you are credited on it as its reporter, and listed among the contributions on the site, by your GitHub username or anonymously, as you prefer.

## What counts

Anything that gets past what the game and the accounts promise, such as:

- seeing the colors of unrevealed cards as a guesser or a spectator, with developer tools or otherwise;
- acting as another player, or taking someone else's seat, room or account;
- logging in to, resetting the password of or binding an address to an account that isn't yours, or learning an account's email address;
- reading anything that the [privacy promises](README.md#privacy) keep from you;
- making the mailer send mail that nobody asked for.

A bug that gives nobody more than they should have goes in a public issue, with the Bug report form.

## Supported versions

Only the latest version on `main` gets security fixes; there are no older versions to patch.
